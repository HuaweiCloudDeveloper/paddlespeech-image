## Project Introduction



[PaddleSpeech](https://github.com/PaddlePaddle/PaddleSpeech) is an open-source toolkit launched by PaddlePaddle for critical tasks in voice and audio. This product provides an out-of-the-box PaddleSpeech based on the Huawei Cloud EulerOS 2.0 64-bit system of Kunpeng servers.

## Core Features

- **Multi scenario speech recognition:** Supports speech recognition for multiple languages and dialects, adapting to the diverse speech to text needs in scenarios such as conferences, customer service, and education
- **High quality identification:** Provide natural and smooth speech to text conversion, and also add punctuation to recognized text to generate better text

The open-source image product [PaddleSpeech speech recognition tool](https://marketplace.huaweicloud.com/intl/hidden/contents/cabd7ec6-916d-4109-a0fb-19f0ce2710e2) provided by this project has pre-installed the the 1.5.0 version of paddlespeech and its related runtime environment, and provides deployment templates. Come and refer to the usage guide to easily start an efficient "out-of-the-box" experience!

> **System requirements are as follows:**
>
> - CPU: 2vCPUs or higher
> - RAM: 4GB or larger
> - Disk: At least 40GB
